# 多多岛 3D 沙盘小火车 | Sodor Railway Sandbox

基于 **Three.js + 纯静态前端 ES5/ES6 脚本** 构建的 3D 沙盘铁路驾驶与调度游戏，支持多型号 3D 机车/动车组/货客车厢编组、7 处交互式 3D 道岔、高架桥/山体隧道/海港/采石场闭环路网、三种视角切换、托马斯互动表情与语音台词，以及本地 `file://` 与 HTTP 双模式无构建运行。

---

## 1. 快速启动与本地开发

项目为纯静态网页，**无需 Node 构建工具**，任意静态 HTTP 服务器或直接浏览器打开 `index.html` 即可运行（外部 3D 模型已封装为 `assets/*-data.js` 内嵌 Base64 GLB 脚本，规避 `file://` CORS 限制）：

```powershell
# 启动本地静态服务器（推荐）
python -m http.server 8765 --directory "E:\VSCODE AI\sodor-train"
# 浏览器访问 http://localhost:8765/
```

语法校验（修改 `js/*.js` 后建议执行）：

```powershell
node --check "E:\VSCODE AI\sodor-train\js\audio.js"
node --check "E:\VSCODE AI\sodor-train\js\track.js"
node --check "E:\VSCODE AI\sodor-train\js\scenery.js"
node --check "E:\VSCODE AI\sodor-train\js\traffic.js"
node --check "E:\VSCODE AI\sodor-train\js\models.js"
node --check "E:\VSCODE AI\sodor-train\js\train.js"
node --check "E:\VSCODE AI\sodor-train\js\main.js"
```

## 3. 核心架构与技术细节

### 3.1 沙盘坐标系与轨距规范 (`models.js` / `track.js`)
- **列车朝向约定**：车头正前方为 `+Z`，上方为 `+Y`，轨道中心线 `X = 0`。
- **标准轨距**：`HALF_GAUGE = 0.575`（总轨距 `1.15`），钢轨顶面高度 `RAIL_TOP_Y = 0.285`。所有外部 3D 模型在 `TrainModelLibrary.instantiateFromLoaded` 中按实测轮缘自动缩放，使左右车轮精确压在 `±0.575` 轨面上。
- **地图缩放比例**：`MAP_SCALE = 5.0`（桌面底盘 `1080 × 760`），满足 16 节（`8+8` 重联）动车组同轨运行、大半径弯道及高架爬坡需求。

### 3.2 铁路路网拓扑与道岔 (`js/track.js` - `TrackNetwork`)
- **路网规模**：共 **22 个节点**、**27 条 Hermite/Catmull 曲线路段**，包含：
  - 内环/中央草甸线（纳普福特站 `E0`、风车支线 `B1~B4`、提茅斯尽头机房线 `S_SHED` 到 `Y1`）
  - 北岭高架与山体隧道主环（`E1~E7`，`N2~N3` 海滨石拱高架桥，`N4~N5` 多多岛山体隧道）
  - 海港与大外环环线（`P1`, `P_HARBOR`, `P2`, `E_SE`, `E_EAST`, `E_NE`, `E_N1`, `E_N2`, `MNT2`, `W_NW`, `W_WEST`, `W_SW`, `W_IN` — `S6` 与 `S8` 已打通形成完整大外环）
- **7 处可控道岔（HUD 按钮、快捷键 `1`~`6`/`8`、`F` 切换前方道岔、点击 3D 道岔或右上角小地图圆点均可扳动）**：
  - `S1` (`N1` 东站分岔)：外环高架桥 / 内环风车线
  - `S2` (`N4` 北岭联络)：山体隧道 / 切入内环
  - `S3` (`M2` 提茅斯机房)：内环主线 / 进机房车库（`Y1` 为尽头缓冲档）
  - `S4` (`N0` 西站合岔)：外环田园 / 内环西支线
  - `S5` (`N7` 西南分岔)：纳普福特站 / 布兰达姆港
  - `S6` (`H2` 海港分岔)：东港联络线 / 外环东大线
  - `S8` (`Q1` 采石场枢纽)：下山回主线 / 西南外环线
- **小地图活跃分支高亮（`js/main.js` `drawMinimap`）**：每个道岔圆点当前连通方向对应的前段线路会绘制与圆点一致的状态色（主线绿 `#22c55e` / 侧线黄 `#f59e0b`），未导通分支维持灰线，方便直观预判行驶去向。
- **工程防穿模规范**：
  - 枕木网格关闭不当剔除并避免地形埋没；高架桥面加宽至 `5.0m`；站台与道岔底座贴地对齐；
  - 接触网电线杆生成时检测周边轨道横向净距，自动避开道岔 V 型岔心，确保杆柱不会立在轨道中间。

### 3.3 列车模型、涂装定制与编组系统 (`js/models.js` / `js/train.js`)
- **7 种可选机车头（`LOCO_CATALOG`）**：
  1. `thomas`：托马斯 1 号（手搓程序化蒸汽机车，支持烟囱蒸汽、连杆运动及交互表情系统）
  2. `bluebaby`：DD17 蓝宝宝蒸汽机车（带 GLTF 轮杆动画与冒烟）
  3. `df4d`：东风 DF4D 内燃机车（`scaleX: 0.0168, scaleYZ: 0.0162`，原红白/复古绿合并，支持 5 区自定义涂装着色）
  4. `nd5`：ND5 (GE C36-7) 重载内燃机车（`specialFix: "nd5GreyBlue"` 渲染为匹配老式车厢画风的灰黑主调 + 做旧灰蓝条纹）
  5. `hxd3d`：和谐 HXD3D 电力机车（原红/蓝合并为单选，在编组弹窗内切换红/蓝涂装，默认挂接黑橙 `mark3_gc` 客车）
  6. `crh_head`：和谐号 CRH3/CRH380B 高速动车组（白底蓝条，已消除车顶接缝黑线并支持停站自动开门 / 行车关门动画，仅可搭配 CRH 专属车厢/尾车，最多支持 16 节双列重联）
  7. `shinkansen_head`：新干线 N700-3000 高速动车（仅可搭配新干线专属车厢/尾车，最多支持 16 节双列重联）
- **自定义编组工厂与 5 区涂装定制**：支持切换 `PRESETS` 预设或点击顶部「自定义组装」自由选择第 1 节车头、总节数（1~16 节）、单节/批量车厢型号及动车组双端流线尾车；当选择 `df4d` 机车或 `mark3_std` / `mark3_buffet` 客车时，可在弹窗内分别定制 **5 个分区颜色**（车顶、车身上部、装饰腰线、车身下部、排障器/裙板）、一键切换 6 组经典配色预设或双向同步涂装。
- **驾驶室视角安全距离（`cabLocalOffset`）**：机车视角相机均设置在前端车鼻外侧/上方净空区，防止穿模遮挡视线。

### 3.4 托马斯 3D 立体笑脸与互动表情系统 (`js/train.js` / `js/audio.js` / `js/main.js`)
- 仅当当前车头为 `thomas` 时，在前端烟室门构建可点击圆脸（`this.thomasFaceHitTargets`）：
  - `CircleGeometry(0.44)` 实时绘制 `512×512` Canvas 2D 表情贴图 + 3D 球体鼻子 + Q 弹点头缩放反馈；
  - 默认展示经典开心笑脸（索引 `0`），左键点击托马斯面部按顺序切换 5 种表情：`经典笑脸` → `调皮得意` → `兴奋开心` → `惊讶哇塞` → `认真鼓腮` → 循环回 `经典笑脸`；
  - 每次点击触发 `audio.playThomasExpressionVoice(expr)`（Web Audio 情绪音效 + 中文语音朗读）并在顶部弹出持续 `3.6s` 的表情台词 Toast。

### 3.5 西海岸双向公路、铁路平交道口与碰撞脱轨系统 (`js/traffic.js` / `js/train.js`)
- **完整闭环双向柏油公路**：沿 `E6` 中点向东西两侧延伸为 `460m` 连续双向柏油公路（含路缘石、双黄线/虚线、停止线、路灯、西端工程物资转盘与东端城镇绿岛转盘），并自动压平公路走廊草坪与避让树木、接触网杆。
- **3 处正交平交道口净空校验**：
  - `西海岸平交道 (S5)` (`E6`, `t = 0.0`, 夹角 `0.0°`, 栏杆净距 `5.36m`)
  - `西岸外环平交道` (`W_WEST`, `t = 126.6`, 夹角 `6.0°`, 栏杆净距 `4.90m`)
  - `西支线平交道` (`B3`/`M3` 处于 `S3` 与 `S4` 之间，已调整 `M3` 节点坐标与切线使轨道垂直穿过公路，`t = -145.0`, 夹角 `0.0°`, 栏杆净距 `4.94m`，彻底消除旧斜交角度下栏杆挡火车的问题)
  - 实时检测机车及全部编组车厢距离与列车速度前瞻，列车接近时自动放下红白电动栏杆、交替闪烁红色信号灯并鸣响道口警铃；正常车流按车头前保险杠与停止线对齐排队，不会卡在栏杆下。
- **多车型程序化 3D 车队（26 辆）**：
  - **重型工程与货运车辆（`isHeavy: true`）**：**特长重型半挂大货车**（`super_trailer`，5 轴 10.4m 超长平板载重设备）、**重型钢卷运输半挂车**（`steel_coil`，4 卷大型钢卷+安全挡板）、**危险品重型油罐车**（`tanker`，被撞击有 `72%` 概率触发**爆炸火球、持续起火火焰与黑烟**）、**大型集装箱半挂货车**（`container`，4 轴牵引车头 + 40 尺瓦楞集装箱）、**水泥搅拌车**（`mixer`）、**渣土自卸车**（`dump`）、**汽车吊工程车**（`crane`）与 **重型平板工程车**（`flatbed`）。
  - **普通车辆（`isHeavy: false`）**：厢式普通运输车（`cargo`）、家庭轿车（`sedan`）与家用 SUV（`suv`）。
- **强行闯栏杆撞断物理、鸣笛救险与局部/全列脱轨物理**：
  - 列车接近道口时有概率随机生成闯栏杆车辆，也可按 `G` 或点击 **「⚠️ 闯栏杆 (G)」** 放行违章车；违章车冲过已落下的道口栏杆时会将**红白电动栏杆撞断**（`_breakBarrier`，外段横杆断裂飞出草地翻滚，12 秒后或复轨时自动修复）。
  - 在普通行驶中看到闪红黄光圈的违章车时，按 **`H` 鸣笛** 可吓停尚未上轨的违章车辆（`tryWhistleWarn`）。
  - **局部与全列脱轨分级物理**：
    - 当列车高速行驶（`|speed| >= 11.0`）且**尾部或中后部车厢（`hitUnitIndex >= 2`）**在道口被重型卡车撞击时，仅**撞击点及相邻车厢**脱节侧翻、后段连带倾倒，已经驶过道口的**前段车头与车厢保持挂钩并稳在轨道上**；
    - 当执行「模拟撞车脱轨」、或机车/第一节高速（`>= 17.5`）及油罐车爆炸正面撞击时，触发全列脱轨侧翻与车厢脱节；撞击小型家用轿车时仅将小车撞飞而不脱轨。脱轨后若有其他汽车驶过，也会与散落路面的脱轨车厢发生二次碰撞。
  - **一键模拟撞车脱轨 & 双模式复轨（一键复轨 / 救援直升机吊装）**：
    - 点击顶部 **「💥 模拟撞车脱轨 (C)」** 按钮，**保留当前所选视角**（`沙盘上帝` 俯瞰道口、`跟随小火车` 追随碰撞、`车头驾驶` 第一视角侧翻倾倒），自动将当前列车高速定位至 `E6` 道口前方并随机派出一名重型工程/集装箱车手冲卡撞断栏杆、触发列车脱轨侧翻与车厢脱节；撞翻的汽车只完成一次侧翻或底朝天翻转并稳稳留在地面，不再反复翻滚或回正。
    - 脱轨后顶部同时弹出 **「🚂 一键复轨 (Z)」**（瞬间复位）与 **「🚁 直升机吊装复轨 (U)」**（`RescueHelicopter` 重型救援直升机自动分析未复位车厢与目标轨位占用关系，优先吊装目标轨位空闲的车厢、遇到互锁占位先暂移至草坪缓冲区后再放回，避免把车头压在倒掉的车厢上；已预留 `setManualMode` / `setManualInput` 接口，便于后续扩展手动操控直升机/吊车吊运车厢）。

## 4. 操作说明与快捷键

| 操作方式 | 功能说明 |
| :--- | :--- |
| `W` / `S` 或 油门滑块 | 增加/减小蒸汽/电力油门 |
| `Space` | 列车刹车 |
| `X` | 瞬间急停 |
| `R` | 切换前进 (`D`) / 倒车 (`R`) |
| `H` 或 鸣笛按钮 | 鸣笛（可吓停接近道口的违章闯卡车；蒸汽机车伴随汽笛白烟） |
| `1`~`6`、`8` 或 `F` | 切换对应编号道岔 / 切换前方最近道岔 |
| 鼠标点击 3D 道岔 / 右上角圆点 | 直接扳动对应道岔 |
| **鼠标左键点击托马斯脸部** | 按顺序切换表情，播放专属语音/音效并弹出台词 |
| `V` 或 顶部视角按钮 | 循环切换视角：`沙盘上帝` → `跟随小火车` → `车头驾驶` |
| 顶部 **「🚦 看道口」** 按钮 | 镜头一键定位至 S5 西海岸平交道口 |
| `G` 或 顶部 **「⚠️ 闯栏杆 (G)」** | 立刻放行一辆强行闯道口栏杆的汽车（会撞断落下中的栏杆） |
| `C` 或 顶部 **「💥 模拟撞车脱轨 (C)」** | 一键模拟高速列车撞击随机大型工程车并脱轨侧翻、车厢脱节 |
| `Z` 或 顶部 **「🚂 一键复轨 (Z)」** | 脱轨后瞬间将车头与车厢重新接轨恢复行驶 |
| `U` 或 顶部 **「🚁 直升机吊装复轨 (U)」** | 召唤重型救援直升机逐节吊起散落车厢并放回铁轨复原 |
| 顶部 **「📖 玩法说明」** 按钮 | 打开图文并茂的儿童友好操作指南弹窗 |
| `M` 或 顶部音效按钮 | 开启/关闭音效与语音 |

## 5. 后续开发注意事项
1. **浏览器缓存刷新**：修改 `js/*.js` 或 `styles.css` 后，请同步递增 `index.html` 末尾 `<script src="js/...js?v=XX">` 的版本号，避免本地测试读到旧缓存。
2. **新增或修改 `thomas` 相关交互时**：在 `SteamTrain.clearRollingStock()` 内务必清理临时命中数组与 CanvasTexture 资源，防止切换机车后出现幽灵点击判定或显存泄漏。
3. **修改路网高度或道岔时**：需重点用「车头驾驶」视角核对隧道净空、高架桥墩/枕木贴合度以及道岔处电线杆横向避让间距。
